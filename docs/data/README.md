# Documentation sample data

These files exist so the documentation examples run **offline and in seconds**, on a CI runner
with no USGS tiles downloaded. They are generated by
[`scripts/make_docs_data.py`](../../scripts/make_docs_data.py); do not edit them by hand.

```
traces/golden_creek.csv   250 points, US-6 west of Golden, CO
traces/carquinez.csv      420 points, I-80 across the Carquinez Strait
tiles/n40w106/            corridor crop covering golden_creek
tiles/n39w123/            corridor crop covering carquinez
```

## These tiles are not real USGS tiles

The `.tif` files are named exactly like the full USGS 1/3 arc-second products, because that is
the layout `USGSLocal` looks for. **They are not those products.** Each one is a small crop of
the real tile, with everything more than 500 ft from its demo trace replaced by the no-data
sentinel. `n40w106` is 535×1060 pixels instead of 10812×10812, and 202 KB instead of 411 MB.

The consequence to watch for: `USGSLocal` returns `NaN` for points it has no data for — it does
not raise. So pointing `USGSLocal("docs/data/tiles")` at any trace other than the two committed
here will silently produce `NaN` elevation rather than an error.

For real work, download the real tiles with `scripts/get_usgs_tiles.py`; see
[Elevation Data](../elevation_data.md).

## Fidelity

Within the retained corridor the elevation values are bit-for-bit the source data — no
resampling, no requantization. `make_docs_data.py` verifies this before it writes anything, by
sampling every demo point through `USGSLocal` against both the full tile and the crop under both
`bilinear` and `nearest` sampling and requiring agreement to within 1e-6 ft. So any number the
docs print is a number the full dataset would also produce.

## Regenerating

Needs the full source tiles (`n40w106`, `n39w123`), which are not in the repository:

```bash
pixi run -e dev python scripts/make_docs_data.py \
    --source-dir /path/to/tiles
```

The trace slice bounds live in the `DEMOS` table at the top of that script. Change a slice and
you must regenerate, or the crop and the trace will disagree and the examples will read `NaN`.
